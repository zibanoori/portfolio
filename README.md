# A clean and simple portfolio template built with pure HTML and CSS

Welcome to my personal portfolio website! This project showcases my journey as a Computer Science student specializing in Backend Python development. The site is designed to be clean, readable, and reflective of my professional identity while maintaining a touch of personal style.

## 🚀 Features
- **Responsive Design:** Fully optimized for desktop, tablet, and mobile devices.
- **Modern UI/UX:** Clean layout with ample whitespace for better readability.
- **Professional Branding:** Integrated links to LinkedIn, GitHub, and Telegram.
- **Typography:** Uses 'Great Vibes' for elegant headings and 'Lato' for clear, easy-to-read body text.
- **Tech Stack Focus:** Highlights my specialization in Python Backend Development.

## 🛠️ Technologies Used
- **HTML5:** Semantic structure for better accessibility.
- **CSS3:** Custom styling with CSS Variables for consistent theming.
- **Font Awesome:** For social media icons and UI elements.
- **Google Fonts:** Great Vibes & Lato font families.
